# SIEM Log Analyzer

Bu script, **SIEM sistemlerindeki log dosyalarını analiz etmek** için geliştirilmiştir.

##  Özellikler
- **SSH Brute-Force saldırılarını tespit eder.**
- **Kritik hata mesajlarını yakalar.**
- **Root kullanıcısına yönelik şüpheli girişimleri inceler.**
- **Tespit edilen olayları bir log dosyasına kaydeder.**

##  Kullanım
Scripti çalıştırmak için:
```bash
chmod +x siem_log_analyzer.sh
./siem_log_analyzer.sh
